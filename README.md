# Bluestock Mutual Fund Capstone Project

## Project Overview
This project analyzes mutual fund industry data using Python, SQLite, SQL, and Power BI. It covers data ingestion, cleaning, exploratory data analysis (EDA), performance analytics, and interactive dashboard development to provide insights into mutual fund performance and investor behavior.

---

## Objectives

- Import and clean mutual fund datasets.
- Store processed data in SQLite.
- Perform SQL-based analysis.
- Build interactive Power BI dashboards.
- Analyze fund performance and SIP trends.
- Generate investor analytics and market insights.
