# Data Dictionary

## dim_fund
- amfi_code : Mutual fund code
- scheme_name : Fund name
- fund_house : AMC name
- category : Fund category

## fact_nav
- nav_date : NAV date
- nav : Net Asset Value

## fact_transactions
- investor_id : Investor ID
- amount : Transaction amount
- transaction_type : SIP/Lumpsum/Redemption
